# 🎮 Mario
Nassim et Redouane

📄 Rapport du projet ([Rapport_Mario.pdf](https://github.com/user-attachments/files/34073114/Rapport_Mario.pdf))

— Présentation de la conception et du développement d’un jeu de plateforme 2D inspiré de Super Mario Bros, réalisé en Processing/Java. Le rapport détaille notamment l’architecture logicielle, la programmation orientée objet, la gestion des collisions, la physique du jeu, les interactions et le système de niveaux.





## 🤝 Workflow Collaboration (Git)

Pour travailler efficacement à plusieur, respectez ces étapes :

1. **Avant de coder** : `git pull`
2. **Après une modif** :
   - `git add .`
   - `git commit -m "Explications de la modif"`
   - `git push`
